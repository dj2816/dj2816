I’m **Dongxu Jiang** — a builder who enjoys connecting physical systems with software.

我喜欢把想法做成真正能运行的东西：从水冷硬件、3D 打印结构到轻量 Web 工具。这里记录的是我的实验、迭代，以及从 “what if?” 到 “it works!” 的过程。

- 🔧 Exploring **hardware prototyping, thermal systems, CAD, and embedded control**
- 💻 Building with **Python, JavaScript, HTML/CSS, and ESP32**
- 🧪 Interested in projects where **mechanical design meets intelligent software**
- 💬 Open to feedback, collaboration, and delightfully over-engineered ideas

<details>
<summary><b>🧭 How I build / 查看我的工作方式</b></summary>
<br />

1. **Observe** — find a real constraint worth solving.
2. **Prototype** — build the smallest version that can teach me something.
3. **Measure** — test fit, temperature, behavior, and failure modes.
4. **Iterate** — document what changed and make the next version better.
5. **Share** — publish files and notes so others can reproduce the work.
